
## GitHub Pages (Voidrey-Kaine.github.io)

The published site lives in `docs/` as plain HTML/CSS/JS — no build step.

1. Push this repo to `Voidrey-Kaine/Voidrey-Kaine.github.io` (branch `main`).
2. On GitHub: **Settings -> Pages -> Source: GitHub Actions** (one time only).
3. Every push to `main` deploys `docs/` automatically via `.github/workflows/pages.yml`.

Alternative: **Settings -> Pages -> Deploy from a branch -> main / /docs**.

Edit `docs/index.html`, `docs/style.css`, `docs/app.js`; images live in `docs/img/`.
